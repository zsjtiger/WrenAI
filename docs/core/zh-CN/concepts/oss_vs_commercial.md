# 社区版与商业版

Janus AI 社区版是完整的引擎：免费、可自托管，并可由一名工程师或一个智能体通过 CLI 和 SDK 驱动。

Janus AI 商业版是同一引擎，面向团队构建。它既可以作为托管的云服务运行，也可以作为自托管的企业部署运行，并增加了 Web UI、账户、托管的访问控制、集成和技术支持。完整概览请参见：[Janus AI 商业版](/cp/overview)。

## 哪个版本适合你

**个人，在终端中工作。** 一名工程师或一个 AI 智能体通过 CLI、SDK 和 Git 工作。社区版即可满足需求。

**数据团队。** 多人需要基于角色和 SSO 的受治理访问，而非技术背景的同事希望在浏览器、Slack 或 Teams 中提问。这正是商业版的价值所在。

**面向客户的分析。** 你把分析功能嵌入自己的产品中，并且每位客户只能看到自己的数据。商业版企业版提供按用户的 RLS/CLS 和多租户隔离。

## 商业版增加了什么

社区版就是完整的引擎。商业版在其之上增加了团队层：

- **自动运行。** 托管云服务或自托管企业版，无需任何人运维整个技术栈。
- **面向人，而不仅仅是智能体。** Web UI 加上 Slack 和 Teams，使非技术背景的同事也能提问。
- **真实的身份与访问。** 账户、角色、SSO、LDAP 和 SCIM，访问控制与真实用户绑定。
- **更多接入方式。** 托管的 API 和 MCP 服务器，以及可自动刷新的仪表盘。
- **信心保障。** 准确率追踪、反馈追溯，以及出现问题时可以求助的团队。
- **无需重建。** 你的 MDL 和上下文可以原样迁移。
