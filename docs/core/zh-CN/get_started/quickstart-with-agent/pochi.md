# 使用 Pochi 安装 Janus AI

Pochi 编程智能体。

## 前提条件

- [Pochi](https://github.com/vercel-labs/skills) 已安装并完成身份验证。

## 安装 Janus 技能

```bash
npx skills add CrossNow/JanusAI --agent pochi
```

## 运行初始化引导

在 Pochi 中打开你的项目文件夹，然后开启一个新的对话会话。

然后提问：

```text
Use the /janus skill to install and set up Janus AI.
```

该技能会引导智能体完成环境检查、配置文件创建、项目结构搭建以及第一条查询。
